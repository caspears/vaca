    🥣 Pandora breakfast / snack decision

    Best timing: after Na’vi River Journey and before entering the 9:00–10:00 Flight of Passage return window. Keep the break short and stay inside Pandora.

    🥇
    Satu’li Canteen
    Best geographic fit. It is in Pandora, offers mobile ordering, and currently lists an 8:00 a.m. opening. Target roughly 8:05–8:35, then approach Flight of Passage before 9:00.
    🥈
    Portable breakfast already carried into the park
    Fastest and safest option if Na’vi runs late. Eat in Pandora without leaving the land.
    🥉
    Creature Comforts before entering Pandora
    Coffee, specialty drinks, and baked goods. It currently opens at 7:30 a.m., but using it after entering Pandora would add backtracking, so use only before the Pandora sequence.
