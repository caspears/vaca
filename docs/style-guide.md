# Documentation Conventions

## Copyable comment conventions

### Family discussion

```markdown
> **Family Discussion**
>
> Add the question or proposed change here.
```

### Open question

```markdown
> **Open Question**
>
> Add the item that still requires research or a decision.
```

### Recommendation

```markdown
> **Recommendation**
>
> Add the recommended approach and why.
```

### Backup plan

```markdown
> **Backup Plan**
>
> Add the alternate plan for weather, downtime, fatigue, or delays.
```

### Personal note

```markdown
> **Review Note — Name**
>
> Add a comment or requested edit here.
```
