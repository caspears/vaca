# August 11 — Magic Kingdom and Hard Rock Transfer

## Daily mission

Use Early Entry and Multi Pass for the highest-rated Magic Kingdom attractions, then transfer to Hard Rock for dinner and pool time.

## Route

```text
Seven Dwarfs → Space Mountain → Friar’s Nook → Haunted Mansion
→ Tiana → Big Thunder → Pirates
```

## Required experiences

1. [Seven Dwarfs Mine Train](https://disneyworld.disney.go.com/attractions/magic-kingdom/seven-dwarfs-mine-train/)
2. [Space Mountain](https://disneyworld.disney.go.com/attractions/magic-kingdom/space-mountain/)
3. [Tiana’s Bayou Adventure](https://disneyworld.disney.go.com/attractions/magic-kingdom/tianas-bayou-adventure/)
4. [Haunted Mansion](https://disneyworld.disney.go.com/attractions/magic-kingdom/haunted-mansion/)
5. [Pirates of the Caribbean](https://disneyworld.disney.go.com/attractions/magic-kingdom/pirates-of-the-caribbean/)
6. [Big Thunder Mountain Railroad](https://disneyworld.disney.go.com/attractions/magic-kingdom/big-thunder-mountain-railroad/)

## Breakfast

[The Friar’s Nook](https://disneyworld.disney.go.com/dining/magic-kingdom/friars-nook/) after the first two rides.
